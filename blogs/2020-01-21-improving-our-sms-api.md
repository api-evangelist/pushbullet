Today we’re making a huge improvement to Pushbullet’s public API by adding support for reliably sending SMS and MMS messages (including picture messages)! The documentation for our new SMS API calls is right here! The new SMS API calls we’ve added make it easy to programmatically send text messages, group messages, and even picture messages.
